# IntelliTask media provenance

These files document the real application interface. No screenshot was drawn
from a mockup. The animated preview is a slideshow assembled from browser
captures; its captions and closing card are presentation elements, not app UI.

## Capture sources

| Files | Source and conditions |
|---|---|
| `screens/01-login.png`, `09-login-tablet.png`, `08-responsive-mobile.png` | Public HTTPS sign-in page at `https://intellitask-v5nc.onrender.com/auth/login`, captured with Chrome/Playwright on 16 November 2026. Viewports: 1440 × 900, 768 × 1024 and 390 × 844. Page returned HTTP 200. The hosted page showed email/password fields, a password-visibility button and a recovery link; it did not show the conditional Google button. |
| `screens/02-supervisor-dashboard.png` through `07-admin-dashboard.png`, plus `10-admin-workers.png` to `12-admin-venues.png` | Actual Flask pages from repository commit `e32c8149d06a9f5e3c96da02d3d177ded7631ee6` on a disposable local SQLite copy. Chrome viewport: 1440 × 900; images use full-page capture, so heights vary. The copied display names, emails, task text and venue details were replaced with synthetic demo values. Password hashes in that copy were replaced with a showcase-only password. No production data was written or published. |

The source SQLite file and its installation-specific JSON mappings stayed
outside Git. The disposable copy was used only to render the protected pages.
Local task counts, assignment statuses and saved-model recommendation scores
were generated by the application from that copy. Captions do not represent
recommendation scores as probabilities or live onboarding outcomes.

## Preview construction

- `intellitask-preview.gif`: 1280 × 720 pixels, 33 frames, 24.56 seconds,
  looping; approximately 1.97 MB. Eight application scenes and a closing card
  use short holds with subtle crossfades.
- `intellitask-preview.png`: 1280 × 720 static first scene for readers who
  prefer a still image.
- Screenshots are resized or cropped for the animation only. Full original
  browser captures remain in `screens/`.
- Supervisor, worker and administrator accents mirror the app's teal, blue and
  purple role themes. The logo on the live login capture comes from the app;
  the closing-card checkmark is an illustration, not a captured app control.

All screenshot links and dimensions can be reviewed from the
[project README](../../README.md#application-screenshots). No passwords,
session cookies, OAuth secrets, database URLs or private email addresses
appear in these committed media files.
